# NEXUS: autonomous software engineering platform

A multi-agent platform of 12 specialised agents across six teams that generate, build and repair customer products end to end. A live Studio screen shows the agents working in real time.

## Status

In active development. It runs locally; a private hosted deployment (backend on Render, frontend on Vercel) is planned once the local test harness passes.

## What it does

- Generates and builds customer products from a brief
- Runs a build-and-repair loop that fixes failing builds
- Studio mission screen with a timeline of the agents at work

## Built with

Python, multi-agent orchestration
